# 注意与空间认知实验（作业二）

基于课堂 Attention Lab 的两个实验重写并改进。**所有界面、绘制与流程代码为本项目自行实现**，只沿用课堂范式的实验逻辑与参数（闪烁 240 ms、YAH 的 9 s 时限等）。

- 实验一：闪烁找不同（Rensink, O'Regan & Clark, 1997）+ **方向箭头线索（75% 有效）**
- 实验二：「你在这里」地图（Levine, 1982；Levine, Marchon & Hanley, 1984）+ **朝向提示（红色视锥）**

## 运行

**直接双击 `index.html` 即可**（单文件版，HTML + CSS + JS 全部内联，不需要服务器、不需要联网就能做完实验）。

被试流程很短：填被试编号 → 实验一 → 实验二 → 「实验结束，感谢参与」。
结果汇总页不给被试入口，需要时直接访问 `index.html#/results`（或独立页 `results.html`，需联网读服务器数据）。

### 改代码后重新构建

`index.html` 是构建产物，源文件仍是 `js/` 下的 ES Module 与 `css/lab.css`：

```bash
node build.mjs        # 重新生成 index.html
```

`src/shell.html` 是单文件版的页面骨架（放置 `{{LAB_CSS}}` / `{{RESULTS}}` / `{{JS}}` 三个占位符），
`build.mjs` 负责把模块转成 IIFE、内联 CSS，并从 `results.html` 抽取结果视图内容。

## 实验一设计

| 项目 | 内容 |
|---|---|
| 范式 | 闪烁范式（原图 240 ms ↔ 灰屏 160 ms ↔ 改图 240 ms ↔ 灰屏 160 ms），单张限时 30 s |
| 场景 | 沿用课堂原项目 **困难档**的 6 个程序化场景（汽车仪表台 / 停车场 / 地铁线路图 / 商业广场 / 邮件收件箱 / 地铁站台），全部为 MI（边缘兴趣） |
| 难度参数 | 困难档：灰屏 160 ms、对比度 70%（`data/design.json` 的 `levels.hard`） |
| 试次 | 6 场景 × 2 轮 = 12；每轮 A/B 呈现顺序随机 |
| **改进** | 每个试次开始前，屏幕中央出现一个指向变化方位的金色箭头（900 ms），**75% 指向正确、25% 指向相反方向**；12 试次中固定 9 次有效、3 次指反 |
| 反应 | 觉察后按空格报时，再用鼠标点击变化位置（±64 px 判对） |
| 数据 | 每次试次记录箭头是否有效、等待时间、是否超时、是否点击、点击坐标与是否命中 |
| 项目码 | `CA7JK4`（experiment = `changeblind_cue_arrow`） |

> 原项目困难档共 8 个场景，其中 `drive3` / `drive4` 需要驾驶模拟器原图（本项目未附带图片素材），
> 因此这里使用其余 6 个程序化场景，仍是原项目「困难」档的素材与参数。

**收数前写下的预测**

1. 箭头有效试次的觉察时间应短于无效试次（线索把注意预先导向正确方位）；
2. 无效箭头（指向相反方向）不仅不应有收益，反而可能更慢——错误定向需要额外的注意转移；
3. 若两者无差异，说明方向信息在长时程的闪烁搜索中作用有限（搜索是串行的、线索收益被 30 s 上限与场景记忆稀释）。

## 实验二设计

| 项目 | 内容 |
|---|---|
| 范式 | 左侧第一人称景象（你正面朝某栋楼）+ 右侧壁挂导览图（红点＝你在这里） |
| 自变量 | 2（朝向提示：无 / 红色半透明视锥）× 3（地图旋转 0° / 90° / 180°），被试内 |
| 试次 | 6 格 × 8 = 48，格内四个方向各 2 次；练习 2 次不计入 |
| **改进** | 有提示条件在地图上画出「你面朝」的扇形视锥，把朝向外部化，理论上免除心理旋转 |
| 反应 | 方向键（↑前 ↓后 ←左 →右），单次限时 9 s |
| 数据 | 提示条件、旋转角、正确答案、实际按键、是否答对、是否属「地图上方＝前方」的系统性错误、RT |
| 项目码 | `3AQE6F`（experiment = `yah_heading_cue`） |

**收数前写下的预测**

1. 无提示条件下复现对齐效应：RT 与错误率随旋转角增大（0° < 90° < 180°）；
2. 有提示条件下旋转效应显著减小——若「旋转成本」解释成立，外部化朝向后应几乎无差异；
3. 错误模式改变：无提示的错误更多落在「把地图上方当正前方」，有提示后趋于随机。第 3 条用于区分「心理旋转成本」与「参照系选择错误」两种解释。

## 已知限制

- 实验一使用原项目「困难」档素材：原档 8 个场景中 `drive3` / `drive4` 需要驾驶模拟器原图（本项目未附带图片素材），故用其余 6 个程序化场景，以「6 场景 × 2 轮」凑到 12 试次；第二轮存在场景记忆，分析时可按 `i<=6 / i>6` 分半检验。
- 困难档变化都很小、30 s 上限下漏检率会偏高，这是难度本身导致的，分析时用「觉察率」而不是只看 RT。
- 每名被试只有 3 个「箭头指反」试次，单被试层面检验力有限，结论应以全班合并为准。
- 本项目不含眼动采集：只用按键、点击与反应时，`file://` 双击即可运行，无需摄像头与本地服务器。
